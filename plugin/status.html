路由配置指南

将任意已入网节点设为全局出口节点或局域网子网路由网关
若要将当前服务器设为出口，直接点击页面上的「开启本机出口」即可一键完成；其他节点请执行：
sudo sysctl -w net.ipv4.ip_forward=1 net.ipv6.conf.all.forwarding=1 && sudo tailscale set --advertise-exit-node
管理台审批 在「子网路由」或节点「路由审批」中批准 0.0.0.0/0
macOS / Windows / 手机 在客户端菜单 Exit Node 中勾选该节点即可全局走代理出网
Linux 客户端 tailscale set --exit-node=出口节点IP
sudo sysctl -w net.ipv4.ip_forward=1 && sudo tailscale set --advertise-routes=192.168.1.0/24
执行后，在本页列表点击该路由右侧「⋯ -> 批准路由」，其他开启了「Use Tailscale subnets / 接收子网路由」的设备即可直接访问该内网网段。
